## 2. Çalışmanın amacı (hatırlatma)

Doğal dil IoT/MEC görev metni → 8 alanlı semantik sözleşme (domain, latency,
privacy, execution_policy, reliability, accuracy, energy_priority, divisibility)
→ PPO/DRL ile local / edge_0..2 / cloud kararı. LLM karar vermez, yalnız
gereksinimi çıkarır. Ana soru: semantik bilginin (ve çıkarım kalitesinin)
gecikme, başarı ve kısıt ihlali üzerindeki nedensel etkisi.

## 3. Literatür güncellemesi (20.11.2026 kontrolü)

- **STEPS** (arXiv 2606.09537) v4, 1 Kasım 2026: semantik ayrıştırma hatalarının
  sisteme etkisini ölçen ek eklendi → "hata yayılımını ilk biz ölçtük" denemez.
  Hâlâ farklar: potential game (DRL değil), 4 alan, privacy/execution permission
  yok, maske yok, tamamen sentetik veri, semantic-on/off ablation yok.
- **Jev Decision Models** (2609.22753): NL isteklerden 4–8 alan, 8.280 doğrulanmış
  istek; küçük model > LLM (gecikme). Bizim "küçük model yeterli" bulgusuyla uyumlu.
- **Personalized Privacy-Aware MARL Offloading** (2611.25800, CloudNet 2026):
  gizlilik ödülde ceza, NL yok, maske yok → bizim "maske vs ceza" (H4) karşılaştırmasının dayanağı.
- LeDRL (2605.05727), COMLLM (2604.07148): kullanıcı NL gereksinimi yok.
- **Savunulabilir boşluk:** NL gereksinim → DRL offloading + privacy/execution
  izinlerinin action mask ile sert kısıt olması + belirsizlik/ihtiyatlı mod +
  gerçek iz güdümlü hibrit ortam + adil semantic-on/off ve çıkarıcı-kalitesi
  → sistem etkisi analizi.
- **Yeniden çerçeveleme:** Ana katkı "belirsizlik-duyarlı semantik kısıt katmanı";
  karar verici (PPO/greedy) değiştirilebilir bileşen.
